# euSindico

Aplicativo de gestão condominial para imobiliárias e síndicos.

O projeto usa Expo Router. A rota inicial está configurada em `src/app/index.tsx` e pronta para receber a interface e os componentes reutilizáveis.

A fonte Inter fica em `assets/fonts/Inter.ttf`, é carregada em `src/app/_layout.tsx` e está registrada nos tokens de `src/theme/tokens.ts`. Para usar em textos, combine `typography.family.primary` com o peso desejado de `typography.weight`.
